# Portfolio — Muhammad Shayan Khan

Personal portfolio site: full stack engineer / AI developer, built as a single-page static site with vanilla HTML/CSS/JS.

**Live:** https://khan-shayan9.github.io/My-Portfolio/

## Sections

- Hero, About & skills
- Services offered
- Selected projects (with links back to their repos)
- Work experience timeline
- Contact — includes a working contact form (EmailJS, no backend) plus a downloadable CV

## Tech stack

- Vanilla HTML/CSS/JS — no framework, no build step
- [EmailJS](https://www.emailjs.com/) for the contact form (sends email directly from the browser)
- Google Fonts (Space Mono, Syne, DM Sans)
- Hosted on GitHub Pages

## Run locally

No build step — just open `index.html` in a browser, or serve it:

```bash
python -m http.server 8000
```

## Deployment

Served directly from this repo via GitHub Pages (`main` branch, root).
